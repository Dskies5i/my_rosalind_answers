# Rosalind Bioinformatics & Algorithmic Solutions

A collection of Python solutions to Rosalind bioinformatics and algorithmic problems covering biological sequence manipulation, genetics, combinatorics, and graph/motif logic.

## Topics & Problem Modules

- **Sequence & Molecular Biology:** RNA-to-protein translation (`translating_rna_into_protein`), point mutations (`counting_point_mutations`), and protein mass calculations (`calculating_protein_mass`).
- **Sequence Alignment, Profiles & Motifs:** Consensus matrices and profile tables (`consensus_and_profile`), shared motifs (`finding_a_shared_motif`), and motif searching in DNA (`finding_a_shared_motif_in_dna`).
- **Genetics & Recurrence / Graph Problems:** Mendelian inheritance (`mendels_first_law`), independent assortment (`independent_alleles`), recurrence relations (`rabbits_and_recurrent_relations`), and overlap graphs (`overlapping_graphs`).
- **Additional Tracks:** Problem folders under `stronghold/` and `village/`.
